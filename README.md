# 千葉工業大学二輪部 公式HP

オフロードとオンロードの両方を紹介する、GitHub Pages 対応の静的サイトです。ビルド工程・外部JavaScriptライブラリは不要です。

## 公開方法
1. このフォルダ内の `index.html`、`images/`、`README.md` を GitHub リポジトリのルートへアップロードします。
2. GitHub の **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、公開ブランチ（通常は `main`）と `/ (root)` を指定して保存します。
4. 表示された GitHub Pages URL を PC とスマートフォンで確認します。

## デザイン・機能
- オフロード：チャコール、オリーブ、土色。地形を感じさせる写真と力強いタイポグラフィ。
- オンロード：明るいアスファルトグレー、ブラック、レーシングレッド。斜めの構図とコーナリング写真を主役にした対照的なセクション。
- 共通ナビゲーションとブランド表現で、ひとつの二輪部として統一。
- WORLD選択リンク、フィールド／車両フィルター、フィルターリセット、横スクロールギャラリー、写真ライトボックス、RIDE STYLE FINDER。
- スマートフォン向けレイアウト、キーボード操作、画像のalt属性、`prefers-reduced-motion` に対応。

## 写真の追加・差し替え
1. `images/onroad/` に画像を追加します。
2. `index.html` の `images/onroad/ファイル名.jpg` を新しいファイル名に変更します。
3. `alt` と `data-lightbox-alt` も写真の内容に合わせて更新します。
4. 既存ファイルと同じ名前で置き換える方法なら、HTMLの変更は最小限です。
